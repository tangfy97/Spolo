# Spolo 产品规划

**Spolo: Merge Videos & Photos**：把一堆照片和视频拼成一个视频，全部在本机完成。
名字来自挪威语 *spole*（胶片卷轴；*spole fram* = 快进）。

## 定位

- **一件事做到最好**：合并。剪切、调速、改比例都是为了合并服务，不做时间线剪辑器。
- **比 Clideo 快**：不上传；能不重新编码就不重新编码。
- **比 JustMerge 稳**：边读边写，不把视频读进内存；几十 GB 也不卡。
- **免费版就好用**：不加水印，不限时长，不限片段数量。
- **私密**：App Sandbox，没有网络权限，没有账号，不统计。
- **原生**：系统控件、系统字体、用户的强调色；中英文（en、en-GB、zh-Hans、zh-Hant）跟随系统语言。
- **系统要求**：macOS 14 或更高，Apple 芯片和 Intel 都支持。不用 Apple Intelligence，所以不需要 macOS 26，用户面比 Rydd 大。

## 用户流程

```
打开 Spolo
  └─ 一个窗口，空白状态：大图标 · “把照片和视频拖到这里” · [添加…]  [从“照片”添加…]
       没有引导页、没有权限弹框：拖进来或在面板里选的文件，沙盒自动允许访问

加素材
  从 Finder 拖入 / 拖到 Dock 图标 / “打开方式” / ⌘O / 从“照片”选（系统照片选择器，不需要相册权限）
  └─ 出现：上方预览播放器，下方胶片条（每个片段一张缩略图 + 时长）
  └─ 打不开的格式（MKV、WebM…）也显示在胶片条里，灰掉，悬停提示“暂不支持这种格式”，不悄悄丢掉

排顺序
  拖动缩略图排序；排序菜单：添加顺序 / 拍摄时间 / 文件名
  （旅行时手机拍的照片和视频混在一起，按拍摄时间一键排好）

调整单个片段（选中后，右侧检查器）
  视频：剪头尾 · 速度（0.25× 0.5× 1× 1.5× 2× 4×）· 静音 · 旋转
  照片：停留时长（默认 3 秒）· 旋转
  多选后可以一起改（比如所有照片 2 秒、所有视频 2×）

整体设置（工具栏）
  画面：自动（跟第一个片段）/ 16:9 / 9:16 / 1:1 / 4:5
  填充：适合（加边）/ 填满（裁切）
  ▶ 播放预览：从头连续播放，所见即所得

导出
  [导出…] → 表单：格式 MP4 或 MOV · 质量：原画质 / 高 / 较小文件 → 存储面板
  └─ 窗口底部进度条 + 剩余时间，可取消
  └─ 完成：在 Finder 中显示 · 共享…
  能“秒出”时（同编码、同尺寸、未调速）自动直接拼接，导出表单里显示“快速导出，不重新编码”

之后
  关掉窗口再打开，上次的片段还在（只记书签，不复制文件）
  ⌘Z 撤销任何调整
```

## 原则（沿用 Rydd 的经验）

- 每个画面只回答一个问题：空白状态问“加什么”，胶片条问“什么顺序”，检查器问“这一段怎么处理”，导出表单问“存成什么”。
- 不写解释性文字；数值和选项本身就是说明，细节放在悬停提示里。
- 只用系统控件：工具栏、检查器（`.inspector`）、分段控件、弹出菜单、标准存储面板和共享菜单。
- 不弹窗打断；出错就在对应片段上标出来。

## 免费版 vs Pro

**免费版**本身就是一个完整、好用的合并工具，用来积累口碑和评分。**Pro** 是一次性买断，不做订阅。

| 功能 | 免费 | Pro |
|---|:-:|:-:|
| 照片 + 视频合并，片段数量和时长不限，无水印 | ✓ | ✓ |
| 混合格式：MOV、MP4、M4V（H.264、HEVC、ProRes）；JPEG、PNG、HEIC、TIFF、WebP、AVIF、RAW | ✓ | ✓ |
| 拖动排序、按拍摄时间排序 | ✓ | ✓ |
| 剪头尾、调速度、静音、旋转、照片时长 | ✓ | ✓ |
| 画面比例 + 适合/填满，黑色边 | ✓ | ✓ |
| 原画质导出，能秒出就秒出 | ✓ | ✓ |
| **压缩到指定大小**（邮件 25 MB、Discord、自定义） | | ✓ |
| **背景音乐**（循环、淡出、原声音量） | | ✓ |
| **转场**（交叉淡化） | | ✓ |
| **模糊背景**填充竖屏/横屏的空白处 | | ✓ |
| **导出 GIF** | | ✓ |
| 以后：倒放、循环、MKV/WebM 导入、标题卡 | | ✓ |

**为什么这样分**：免费版就打掉了 Clideo 和 JustMerge 的最大痛点（水印、上传、死机）。Pro 卖的是“多走一步”的需求：发出去之前要压缩、要配乐、要好看。这些都是搜索量大、愿意付钱的场景，其中“压缩视频”的搜索量比“合并视频”还大。

**价格建议**：Pro 一次性 $9.99（Permute 是 $14.99，JustMerge 订阅 $14.99/年）。用 App Store 内购，非消耗型，可恢复购买。

## 技术要点

- **合成**：`AVMutableComposition` 拼接；自定义 `AVVideoCompositing`（Core Image）处理缩放、旋转、加边、模糊背景；照片在合成器里画成静止画面，不先转成视频文件。
- **调速**：`scaleTimeRange`；声音用 spectral 算法保持音调。调速的片段必须重新编码。
- **秒出**：所有片段编码、尺寸、帧率一致且没有调速和旋转时，用 passthrough 直接拼接。
- **导出**：常规用 `AVAssetExportSession`；压缩到指定大小用 `AVAssetWriter` 按目标码率编码（大小 ÷ 时长，留出音频）。
- **内存**：只读缩略图和当前帧，永远不把整个视频读进内存。
- **要提前测的坑**：iPhone 的 HDR（HLG）和 SDR 混在一起时的色调映射；可变帧率的录屏；没有音轨的片段（补静音）；采样率不同的音频；Live Photo（v1 只取静态照片）。
- **不支持的格式**：MKV、WebM、AVI、WMV、FLV 系统读不了。v1 不做；以后再评估 MediaExtension 或 LGPL FFmpeg。
- **沙盒权限**：用户选择的文件可读写、app-scope 书签（恢复上次的片段）；照片选择器不需要权限；没有网络权限。

## 版本节奏

1. **1.0**：免费版全部功能，上架 Mac App Store + 官网 DMG + GitHub，和 Rydd、Kvikkshot 一样。
2. **1.1**：Pro 内购（压缩到指定大小、背景音乐、转场、模糊背景、GIF）。
3. **之后**：根据评价和反馈决定倒放、循环、MKV/WebM。
